# `@workspace/ui`

Shared shadcn/ui primitives, fonts, and global Tailwind styles, implementing the repo's neobrutalist design system.

See `docs/ui/design-system.md` for the full token model (borders, shadows, radius, motion) and `docs/ui/font-stack.md` for the font-loading convention. Add new shadcn primitives with `pnpm dlx shadcn@latest add <name> -c apps/web` — the CLI auto-routes base components here.
